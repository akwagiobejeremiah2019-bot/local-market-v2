# Local Market

A location-based marketplace for buying, selling and discovering local
businesses — built with Next.js and Supabase.

## What's included
- Email/password sign up & login (password reset, Google sign-in ready)
- Browse, search, and filter by category
- Post a listing with a photo
- Listing detail page with seller contact info
- Profile page showing your own listings

## Already done
- Supabase project created
- Database tables + security rules set up
- Image storage bucket created
- Code pushed to GitHub

## Next: deploy on Vercel
1. Go to vercel.com, sign up free, "Add New → Project"
2. Import this GitHub repo (local-market-v2)
3. Add environment variables:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
4. Click Deploy
